Kullanılan teknolojiler ve mimari. Frontend: Next.js, React, Tailwind CSS. Backend: FastAPI, Python (Hızlı API yanıtları ve yapay zeka entegrasyonu için seçildi). Veritabanı: Supabase (PostgreSQL, Auth, RLS). Yapay Zeka: Oyuncunun hata ve süre performansını analiz edip bir sonraki seviyenin matematiksel karmaşıklığını ayarlayan özel bir 'Flow State Engine' (Akış Durumu Motoru) otonom ajanı tasarlandı.
